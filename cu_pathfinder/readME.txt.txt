CU- path finder 
This program is completely made on python 
The program was made with AI based on an image I made from a satellite picture of the campus 
The UI although irrelevant is minimal and has wrong calibration 
The program works on 4 search algorithms  BFS,DFS,UCS & A*
The distances are somewhat correct 


To run this program 
we need to open the folder in the terminal and give the command "python map_ui.py" (assuming the file name is the same)
the user has to choose start point and destination and the algorithm 
the path glows up 

the user can also zoom in and out on the MAP
It took 1hour to make the map 
and 20 mins to get and integrate code made by AI
